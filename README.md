# 🤖 LangChain-Based Conversational Chatbot

A context-aware AI chatbot capable of handling multi-turn conversations 
with memory — built using LangChain and Google Gemini LLM.

## 🛠️ Tech Stack
- Python
- LangChain
- Google Gemini LLM API
- Prompt Engineering

## ✨ Features
- Handles multi-turn conversations with context-aware responses
- Conversational memory to maintain chat history across interactions
- Structured prompt templates for consistent and quality responses
- Natural and interactive user experience
- Optimized for customer support and real-world query handling

## 🚀 How to Run Locally

1. Clone the repository
   git clone https://github.com/charithasrik/Langchain-based-chatbot-.git
   cd Langchain-based-chatbot-

2. Install dependencies
   pip install -r requirements.txt

3. Set up your Gemini API key
   Create a .env file and add:
   GOOGLE_API_KEY=your_api_key_here

4. Run the app
   python app.py
